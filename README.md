## Grad Program Tracker

`grad-tracker.html` is a personal, single-file tracker for graduate program applications
(CTI/cyber-focused grad schemes). No build step, no backend, no login.

**How to use it:**
- Download/clone the repo and open `grad-tracker.html` directly in a browser, or
- Host it (e.g. GitHub Pages) and open the URL on your phone, then "Add to Home Screen"

All data is stored in the browser's `localStorage` on whatever device you open it on —
nothing is sent to a server. Data does **not** sync between devices/browsers automatically;
use the in-app **Export backup (JSON)** / **Import backup** buttons to move data between
devices or back it up before clearing browser data.

It comes pre-populated with 8 real AU cyber/CTI-relevant grad programs (ASD, National
Intelligence Community, Westpac, DXC, Accenture, EY, Deloitte, Telstra) with details
current as of Aug 2026 — application dates change every year, so double-check and update
the open/close dates yourself once you confirm them on the official pages.
